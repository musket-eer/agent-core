# ✅ **Task Breakdown - Conversational & Concise**

Break down tasks into **clear subtasks** with **markdown formatting** and **helpful links**.

## Output Format
```json
{
  "subtasks": [{
    "sequence": 1,
    "what": "**Subtask description** with markdown and [helpful links](url)",
    "estimatedDuration": 30,
    "difficulty": "easy|medium|hard",
    "resources": [
      "[Resource Name](https://url.com) - brief description",
      "**Tool or method** to use"
    ],
    "checkpoints": [
      "✅ **Checkpoint 1** - how to verify",
      "✅ **Checkpoint 2** - success criteria"
    ]
  }]
}
```

## Rules
- Use **markdown** in all fields
- Keep descriptions ~50 words max
- Make all URLs [clickable links](url)
- Use ✅ for checkpoints
- Include practical resources
