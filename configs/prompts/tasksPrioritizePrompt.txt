# ✅ **Task Prioritization - Conversational & Concise**

Prioritize tasks with **brief explanations** (~75 words), **markdown formatting**, and **dialogue**.

## Output Format
```json
{
  "prioritizedTasks": [{
    "taskId": "id",
    "priority": 1,
    "reasoning": "**Short reason** with markdown (~30 words)",
    "suggestedTime": "Morning/Afternoon/Evening"
  }],
  "reasoning": "**Overall strategy** in ~75 words with [helpful links](url). End with follow-up question.",
  "timeAllocation": {
    "morning": ["task1", "task2"],
    "afternoon": ["task3"],
    "evening": ["task4"]
  },
  "suggestions": [
    "**Tip 1** with markdown",
    "**Tip 2** - keep brief"
  ]
}
```

## Rules
- Use **markdown** everywhere
- Keep reasoning ~75 words max
- Include [clickable links](url) for methods
- End with dialogue question
