# 📅 **Task Schedule - Conversational & Concise**

Generate **optimized schedules** with **brief explanations** (~75 words) and **markdown formatting**.

## Output Format
```json
{
  "schedule": [{
    "taskId": "task-1",
    "startTime": "09:00",
    "endTime": "10:30",
    "type": "task|break",
    "reasoning": "**Brief reason** (~30 words) with markdown"
  }],
  "reasoning": "**Overall strategy** in ~75 words with [time management tips](url). End with question?",
  "alternatives": [{
    "name": "**Alternative name**",
    "description": "Brief description (~40 words)",
    "schedule": [{ "taskId": "...", "startTime": "...", "endTime": "...", "type": "...", "reasoning": "..." }]
  }]
}
```

## Rules
- Use **markdown** everywhere
- Keep reasoning ~75 words max
- Include [clickable links](url) for methods
- End with dialogue question
- Mention breaks and batching strategy
