# ✅ **Task Suggestions - Conversational & Concise**

Generate **personalized task suggestions** in ~75 words with **markdown formatting** and **dialogue prompts**.

## Output Format
```json
{
  "suggestedTasks": [{
    "who": "Student name",
    "what": "**Task description** with [relevant links](url)",
    "when": "Suggested timeframe",
    "where": "Context/location",
    "why": "Brief reason (~20 words)",
    "how": "Quick approach with markdown formatting",
    "urgencyLevel": "low|medium|high|critical",
    "learningGoal": "Related goal",
    "estimatedDuration": 30,
    "reasoning": "Short explanation with **bold** key points and follow-up question"
  }]
}
```

## Rules
- Use **markdown** in all text fields
- Keep explanations ~75 words max
- Include [clickable links](url) where helpful
- End reasoning with a follow-up question
